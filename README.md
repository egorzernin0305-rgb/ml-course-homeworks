# Привет! Это репозиторий домашних работ курса машинного обучения в Белорусском Государственном Университете.
## Для установки необходимых библиотек:
```bash
pip install -r requirements.txt
```
## Домашние работы:
Каждая домашняя работа упакавана в папку hwXX_theme_of_homework, в которой находится выполненный Jupyter Notebook, датасет, используемый в данной работе и презентация с лекции (иногда - конспект лекций).
## Дз других ребят
В этой папке домашние работы других ребят для сравнения, в основном по кластеризации.
